# daily-log v1.0.0

- Version: `v1.0.0`
- Summary: This is the first formally deployable release of `daily-log`.

## Highlights

- Docker Compose can start the frontend, backend, and PostgreSQL together.
- The frontend now uses the real HTTP API by default in Docker deployments.
- Task and event completion state is persisted through the backend.
- The calendar week view now supports quick completion for overdue history items.
- The tasks page now supports completion toggles for events.

## Deployment

See the deployment and operations sections in [README.md](../../README.md).

## Known Limitations

- The current deployment flow still builds images from source on the target server.
- There is no published image registry distribution flow yet.
- There is no CI/CD-based automatic release or cloud deployment yet.
