## 主面板
![](picture/主页面.png)

### 概览

核心是三个模块: 时间轴、待办事项、随笔

### 待办事项

核心字段说明:
- title: 标题
- detail: 细节, 详情
- 截止时间: 默认是23:59
- 是否完成

页面说明:
- 该列只显示未完成、未超时的待办事项

### 时间轴

`日程`核心字段说明
- title: 标题
- detail: 细节, 详情
- 开始时间
- 结束时间
- 是否完成

时间轴卡片类型: (判断变量: 当前时间)
- 未开始日程: 蓝色
- 已完成日程、已完成待办: 绿色、删除线
- 超时日程、超时待办: 红色

补充说明:
- 只有已完成和超时的待办会插入到时间轴
- 日程和待办的卡片要有细节区分

### 随笔
包含title和内容

### 密码库

密码库使用独立页面 `/passwords`。

核心原则:
- 根密码只在浏览器内用于确认身份和派生加密密钥
- 根密码不保存、不发送给后端、不写入 localStorage
- 保存的密码条目必须先加密再持久化
- 标题、站点名、用户名、密码、URL、备注等条目内容全部加密

加密设计:
- KDF: PBKDF2-SHA256
- Cipher: AES-GCM-256
- 每个 vault 保存随机 salt、迭代次数、加密算法和 verifier 密文
- 每条密码记录使用独立随机 IV
- 解锁成功后的 CryptoKey 只保存在当前页面内存中，刷新或锁定后清空

API 约定:
- `GET /api/password-vault`: 读取 vault 元数据
- `POST /api/password-vault`: 初始化 vault 元数据
- `GET /api/passwords`: 读取加密后的密码记录
- `POST /api/passwords`: 新增加密后的密码记录
- `PATCH /api/passwords/:id`: 更新加密后的密码记录
- `DELETE /api/passwords/:id`: 删除密码记录

开发环境 mock 存储:
- `mock_password_vault_meta` 只保存 salt、iterations、算法名和 verifier 密文
- `mock_password_entries` 只保存 ciphertext、iv、id、时间字段
- 不应出现明文根密码、标题、用户名、密码、URL 或备注

安全边界:
- 客户端加密保护的是静态存储数据
- 页面已解锁时，XSS、恶意浏览器扩展或被篡改的运行时代码仍可能读取明文
